# Laura Leal-Taixé — personal website

A responsive, static personal website for https://lealtaixe.github.io/.
The website has one page, ordered Bio, Publications, Jobs, and Education.
Publications links to SIL's papers page. Jobs includes current roles and
career history. The portrait is circular, and email contact links are omitted.

## Preview and edit

Open `index.html` in a browser. Edit `index.html` for the content and
`styles.css` for the layout and colors. The site works without JavaScript,
a build step, or external font services.

The accent is NVIDIA green (`#76b900`). Text links use a darker green
(`#477600`) for readable contrast. NVIDIA Sans is included locally in
regular, medium, and bold weights. Font sources and the license reference
are recorded in `assets/fonts/NOTICE.txt`.

## GitHub Pages

Publish the contents of this folder to the root of
`lealtaixe/lealtaixe.github.io`, on the branch configured for GitHub Pages.
The `.nojekyll` file enables direct static hosting.
